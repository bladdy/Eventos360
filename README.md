# 🎉 Eventia – Directorio de Proveedores para Eventos

Eventia es una plataforma web moderna diseñada para conectar organizadores de eventos con proveedores de servicios para fiestas y eventos sociales, tales como salones, banquetes, DJs, animadores, renta de mobiliario y más.

La aplicación funciona como un directorio digital donde los usuarios pueden buscar proveedores por categoría y ubicación, visualizar perfiles detallados, comparar servicios y contactar directamente a los proveedores.

## 🚀 Características principales

- 🔍 Búsqueda y filtrado de proveedores por categoría y ciudad
- 🏷️ Directorio organizado por tipos de servicios para eventos
- 📄 Perfiles detallados de proveedores con galería de imágenes
- ⭐ Sistema de reseñas y calificaciones
- 📞 Contacto directo vía WhatsApp, teléfono o sitio web
- 👤 Registro e inicio de sesión para usuarios y proveedores
- 🧑‍💼 Panel de administración para gestión de proveedores y categorías
- 🧑‍💻 Panel de proveedores para administrar sus anuncios

## 🛠️ Tecnologías utilizadas

- **Frontend:** Blazor WebAssembly
- **Backend:** ASP.NET Core Web API (.NET 8)
- **Arquitectura:** Clean Architecture / DDD
- **Autenticación:** JWT
- **ORM:** Entity Framework Core
- **Base de datos:** SQL Server
- **UI:** Componentes reutilizables y diseño responsive

## 📐 Arquitectura

La solución está dividida en capas para garantizar escalabilidad y mantenibilidad:

- **Domain:** Entidades y reglas de negocio
- **Application:** DTOs, servicios y casos de uso
- **Infrastructure:** Acceso a datos y servicios externos
- **API:** Endpoints REST
- **Client:** Blazor WebAssembly

## 🎯 Objetivo del proyecto

Este proyecto tiene como objetivo servir como base para un sistema real de directorio de proveedores de eventos, permitiendo su escalabilidad hacia modelos de suscripción, proveedores destacados, promociones y monetización.
